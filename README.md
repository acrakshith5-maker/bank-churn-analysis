# Bank Customer Churn Analysis

A first hands-on data analysis project exploring which factors relate to customer 
churn using a bank customer dataset (10,000 customers) from Kaggle. Using Python 
(pandas, matplotlib), I compared churned vs. retained customers across age, 
account balance, number of products, and membership activity.

Key finding: account activity showed the strongest relationship with churn — only 
36% of churned customers were active members, compared to 55% of retained customers. 
Churned customers also tended to be older (avg. 44.8 vs. 37.4 years) and held higher 
average balances (€91,109 vs. €72,745), which was a more counter-intuitive pattern 
worth further investigation.
